Scrum Board — Playful themes

Six playful color schemes for casual users to choose from, each drawn next to Night shift (the current dark design). Every board here is the same markup with one class swapped, so cards, buckets, buttons and chips have exactly the same size and place in all of them. A scheme only changes colors, the font family (at the same sizes), corner radii, shadows and decorations that take no room. Click a board to look at it closer below.

Notes for building any of them

WhatHow
Where it goesOne more block :root[data-theme='…'] in index.css next to Positivity with the scheme's tokens, and a choice in ColorSchemeToggle / theme.ts. The bars set their own text tokens, as Positivity's navy bars do.
Sizes stay putSame font sizes and line heights, paddings, gaps and border widths. What's new takes no room: the card decoration is a ::before, the bucket dot sits in the gap the name row already has, hover tilts are transforms, Pop's ink outline and every hard shadow are box-shadows, and the photo edge is a border Night shift draws transparent.
New tokensRadii, shadows and a few looks are hard-coded today. Make them tokens on :root with today's values, so Productivity and Positivity don't change: --font, --tag-font, --title-weight, --r-card, --r-bucket, --r-panel, --r-button, --r-small, --r-tag, --card-shadow, --card-shadow-hover, --card-hover, --bucket-shadow, --corner and the --deco-* set for the card decoration.
FontsEach scheme can use its own family (Nunito, Fredoka, Rubik, Kalam, Bricolage Grotesque, Quicksand; all Google Fonts under the OFL). Self-host the one picked, as Geist is today. Boxes keep their sizes; only where a long title or tag row wraps can differ a little. Counts and the zoom level stay Geist Mono.
Fill namesEvery scheme keeps Butter, Mint, Sky, Coral and Lilac (search words, exports), even where the shade moves (Pop's Coral is a tomato red, Pool party's Sky a bright blue).
TexturesChalkboard paints the board, the bar and the card decoration in CSS gradients: --ground-image/--ground-size replace the dot grid, --bar-image draws the wooden planks, and --pin gives each card's magnet its color (in the app, from the card's number).
Bucket color dotBuckets have no color today: cycle the fills by list order, add a bucket color to the API, or drop the dot.
Far zoom.canvas.far already drops shadows; drop the card decoration there too, and Pop's outline can go with the shadow.
